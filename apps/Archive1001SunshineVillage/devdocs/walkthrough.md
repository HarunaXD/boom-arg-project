# 《阳光新村 BBS》通关流程文档

> 维护规则：任何会改变主线解锁条件、支线发现方式、结局判定、关键页面入口或测试流程的改动，都必须同步更新本文档。

本文档描述当前版本玩家需要完成的必要通关操作，以及可发现、可解决的支线内容。它既可作为玩法验收清单，也可作为 Playwright 测试流程维护参考。

## 一、主线通关必要流程

### 1. 进入主线帖

1. 打开游戏首页。
2. 点击首页快捷入口「进入置顶热帖」。
3. 进入闲聊茶馆置顶帖《大家今天吃了吗？》。

当前主线帖共有 50 页，但页面上限受阶段锁控制：

- 初始只能进入第 1-15 页。
- 解锁老赵线索后开放第 16-30 页。
- 解锁空间侵蚀证据后开放第 31-45 页。
- 解锁 UID 334 清醒者证据后开放第 46-50 页。

### 2. 第一阶段：通过引用链找到老赵

必要操作：

1. 在《大家今天吃了吗？》中翻到第 8 页。
2. 找到含有 `引用自 #009 / 处理记录 009` 的引用残留。
3. 点击该引用入口。
4. 进入站务反馈帖《【申诉】凭什么封我号！我没疯！》。
5. 阅读老赵关于墙体、黄黏液和墙面回缩的申诉内容。

效果：

- 触发 `s1`。
- 解锁主线第 16-30 页。
- 搜索 `老赵` 或 `009` 仍可作为隐藏捷径，但推荐流程是通过引用链发现。

补充线索：

- 第 12 页也有 `引用自 #009 / 墙皮软化`。
- 搜索 `墙`、`黄水`、`凿墙`、`回缩` 等敏感词时，搜索页会显示屏蔽表处理记录，而不是直接给攻略式结果。

### 3. 第二阶段：收集空间证据并比对户型图

必要操作：

1. 返回主线帖《大家今天吃了吗？》。
2. 翻到第 16 页，找到 `缓存字段：302 / 客厅 / 泡沫垫尺寸异常`。
3. 点击该缓存字段，记录第一条空间证据。
4. 翻到第 17 页，找到 `缓存字段：402 / 主卧 / 床位回退`。
5. 点击该缓存字段，记录第二条空间证据。
6. 回到首页，点击「查看户型图」。
7. 在户型图上确认红色手写标注和扫描仪批注。

效果：

- 户型图显示至少 2 处尺寸不一致。
- 中央井标签从「公共电梯井」异变为「公共井 / 胃井 / 井内侧」。
- 触发 `s2`。
- 解锁主线第 31-45 页。
- 空间阶段后，部分用户资料卡会出现「曾用房号」，暗示门牌和身份边界开始回流。

可替代空间证据：

- 第 18 页：`602 / 门框 / 开合不足`。
- 二手交易、家具相关支线也提供空间侵蚀氛围，但当前必要流程只要求至少两条空间证据。

### 4. 第三阶段：通过 UID 334 个人历史聚合找到清醒者线索

必要操作：

1. 回到主线帖。
2. 翻到第 38 页。
3. 点击 UID 334「失眠的猫」的用户名或头像，进入个人主页。
4. 阅读个人日志《通风口尺寸有点奇怪》。
5. 查看「发帖历史」中的历史聚合残留。
6. 在「相册 / 附件」中点击 `vent_334.tmp`。
7. 确认附件返回 `404 Not Found`。

效果：

- 记录清醒者证据。
- 记录附件残影证据。
- 触发 `s3`。
- 解锁主线第 46-50 页。

设计说明：

- 当前版本已移除“白字直给”提示。
- UID 334 的线索来自个人主页聚合后的残留信息：`去我主页 / 封风口 / 别睡熟`。
- `vent_334.tmp` 不显示真实文件，只作为损坏附件残影记录进证据日志。

### 5. 终局：merge_target

必要操作：

1. 回到主线帖。
2. 翻到第 50 页。
3. 找到底部输入框，标签为 `merge_target = ____`。
4. 输入 `1001`。
5. 点击确认。

效果：

- 触发 `s4`。
- 页面进入系统接管演出。
- 显示归档报告。
- 点击最终确认后下载 `archive_1001_final.txt`，页面转为 `404 Not Found`。

错误输入行为：

- 如果输入非 `1001`，不会弹出错误。
- 页面会生成一条 UID 1001 临时归档回复，例如：`merge_target 接收到“302”。字段未匹配，内容转入 UID 1001 临时回复。`
- 错误输入不推进结局。

## 二、支线发现与解决

### 0. 超自然归档系统迹象

这些不是硬性锁，但属于当前版本需要维护的“系统正在整理玩家”的核心体验。

- 首页「最近浏览」会混入玩家尚未访问过的预言项，例如 `#009 / 处理记录`、`402 主卧`、`通风口`、`merge_target=1001`。
- 搜索框输入敏感词时会出现问题式补全，例如 `你为什么还在查`、`你住哪一户`、`请确认是否封堵通风口`。
- 锁住的分页按钮带有预言性 title：
  - 第 16 页：`处理记录 009 缺失`
  - 第 31 页：`你还没有量完`
  - 第 46 页：`还有一个人醒着`
- `s2` 后，部分帖子文本会被官方措辞污染，例如“墙体回缩”被改写为“建材沉降”。
- `s3` 后，版块主题时间会显示为 `2003-08-14 03:02`，像被按归档完成时间重新排序。
- `s3` 后，资料卡会出现 `查看者房号：未分配`、`查看者最后登录：2003-08-14 03:02`。
- 个人主页附件列表会出现当前日期附件，例如 `visitor_2026-06-15.tmp`。该附件不使用真实隐私信息，只使用当前日期制造“归档仍在继续”的感觉。
- 第 46-50 页逐渐不再像帖子，而像数据库行：`uid=1001 room=all floor=... archive_id=1001 content=...`。

### 1. 猫与通风口支线

入口：

- 闲聊茶馆主题《猫一直盯着通风口，是不是里面有老鼠？》。
- 主线第 7、20、47 页也有通风口和动物反应相关内容。

解决方式：

1. 打开该支线主题。
2. 阅读 UID 334 楼中楼回复：`不是老鼠。你听见它叫的时候，先别吸气。`
3. 之后进入 UID 334 个人主页，点击 `vent_334.tmp`。

作用：

- 强化通风口是关键系统而非普通装修问题。
- 与 UID 334、附件残影、身份融合证据组合后，可进入清醒结局。

### 2. 密码互登 / 身份融合支线

入口：

- 搜索 `密码`。
- 或进入站务反馈主题《密码没改过，为什么我能登进我爷爷的号？》。

解决方式：

1. 打开密码互登主题。
2. 点击 `缓存字段：密码所有者互换`。
3. 阅读王家大孙子、王大爷与清风的回复。

作用：

- 记录身份融合证据。
- 是证据结局和清醒结局的重要组成条件。
- 解释后期 UID 1001 并不是账号 bug，而是人格边界被合并。

### 3. 物业改稿 / 掩盖支线

入口：

- 搜索 `修订`。
- 或进入物业公告主题《入住须知修订记录 2003-08-13》。
- 也可进入《关于近期报修口径统一的内部通知》。

解决方式：

1. 打开修订记录主题。
2. 点击「查看 修订前版本」。
3. 阅读被替换掉的词：`墙体回缩`、`通风口扩大`、`黄色黏液`、`软组织`、`电梯井内侧`。

作用：

- 记录物业掩盖证据。
- 结局报告会增加 `coverup_revision_count`。
- 支线解释为什么公告区总用“建材沉降”“风压变化”等官方措辞覆盖异常。

### 4. 空间侵蚀 / 家具支线

入口：

- 二手交易版块：
  - 《急售1.8米双人床，主卧放不下了》
  - 《低价出大衣柜，以前正好的地方现在门关不上》
  - 《出儿童床，次卧越来越小，孩子都不敢一个人睡了》
- 主线第 16-30 页。

解决方式：

1. 阅读家具主题和主线空间异常页。
2. 关注房号、房间位置和靠井关系。
3. 回到户型图验证这些房间是否贴近公共电梯井。

作用：

- 帮助玩家理解空间正在向中央井收缩。
- 当前主线必要条件仍以主线第 16、17 页缓存字段为最短路径。

### 5. 门牌回流支线

入口：

- 主线第 22、34、37 页。
- 空间阶段后查看相关用户资料卡。

解决方式：

1. 完成空间证据并触发 `s2`。
2. 查看小周、孙姐、清风、小宝妈、UID 334 等人的资料卡。
3. 注意资料卡中的「曾用房号」。

作用：

- 暗示房号不再是固定空间坐标。
- 让玩家意识到“房间变小”之后，身份和地址也开始错位。

### 6. 相册 / 附件残影支线

入口：

- 个人主页。
- 当前有附件残影的用户包括：
  - UID 334：`vent_334.tmp`、`all_faces.dat`
  - 当前查看者日期附件：`visitor_YYYY-MM-DD.tmp`
  - UID 142：`bed_402.jpg`
  - UID 225：`yangtai.jpg`

解决方式：

1. 进入对应用户个人主页。
2. 在「相册 / 附件」模块点击附件名。
3. 看到 `404 Not Found`。

作用：

- 点击带证据字段的附件会记录附件残影证据。
- UID 334 的 `vent_334.tmp` 是清醒结局必要证据之一。
- `visitor_YYYY-MM-DD.tmp` 不记录真实玩家信息，只作为超自然归档系统仍在运行的氛围证据。

### 7. 夜班门卫支线

入口：

- 站务反馈主题《门卫夜班巡逻记录，6栋电梯口总有人影》。
- 夜归人个人主页日志《夜班回家路线》。

解决方式：

1. 阅读夜班记录主题。
2. 注意巡逻本里多次出现“有人站内侧”，但电梯门未打开。
3. 查看夜归人个人主页，读到他放弃乘坐 6 栋电梯。

作用：

- 补充“井内侧”不是建筑空间，而像某种正在学习住户行为的结构。
- 当前不作为必要结局条件。

### 8. 水表倒转与家常污染支线

入口：

- 闲聊茶馆主题《水表倒着转，是不是管道里进空气了？》。
- 主线前期饭菜、买菜、借物相关日常帖。
- 主线后期关于炖、焖、收汁、入味、软烂等消化隐喻。

解决方式：

1. 阅读前期日常帖，建立普通生活感。
2. 后期回看相似词语，意识到早期生活词汇正在被后期归档文本污染。

作用：

- 不提供硬性状态锁。
- 主要用于提升玩家“越回看越不对”的沉浸感。

## 三、结局判定

### 基础结局

达成方式：

- 只完成主线必要流程。
- 不完整收集空间、物业、身份、清醒者、附件等证据组合。

报告特征：

- 显示 302 名住户已完成数据合并。
- 建筑消化完毕，进入休眠期。
- 等待二期业主入住。

### 证据结局

达成方式：

- 记录空间证据。
- 记录物业掩盖证据。
- 记录身份融合证据。

报告特征：

- 归档报告出现未清理字段：
  - `room_width`
  - `password_owner`
  - `property_notice`
- 显示 `coverup_revision_count`。

### 清醒结局

达成方式：

- 记录清醒者证据。
- 点击 UID 334 的 `vent_334.tmp`，记录附件残影证据。
- 记录身份融合证据。
- 可额外记录物业掩盖证据，以增加 `coverup_revision_count`。

报告特征：

- 归档报告出现 `awake_user residue detected`。
- 下载文件追加：
  - `AWAKE_USER_RESIDUE=334`
  - `VENTILATION=SEALED`
  - `coverup_revision_count=...`
